## 项目简介

「山河之间」是 1911—1949 年中国近代历史态势概览的单文件交互式地图应用。以 **39 个年度画面**逐年呈现民国三十八年间的政治态势演变，配时间轴导航、自动播放与逐年史料说明。

**注意：本图为教学示意，非精确疆界。**

## 功能特点

- **39 个年度画面**：1911（辛亥革命）至 1949，逐年呈现历史态势
- **自动播放**：▶ 播放键自动流转年份，↺ 一键回到 1911 年
- **时间轴快捷跳转**：1911 / 1920 / 1930 / 1937 / 1945 / 1949 关键年份直达
- **查看本年参考资料**：每年配「史料与读图说明」弹窗，引用 FRUS 外交文件、各地党史方志、档案馆等一手来源
- **保存本年地图 SVG**：一键导出当年地图为 SVG 文件
- **了解编绘方法**：附编绘方法与读图注意事项说明

## 技术栈

- 纯 HTML / CSS / JavaScript **单文件应用**，零外部依赖，双击即用
- 内嵌 SVG 地图与年度数据
- Noto Sans / Serif CJK 字体子集以 WOFF 内嵌，离线显示效果一致
