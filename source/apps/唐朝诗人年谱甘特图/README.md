# 唐朝诗人年谱甘特图

## 项目介绍

将 50 位唐朝诗人按生卒年排成 Excel 甘特图：横轴 580—929 年、每 5 年一列，甘特条由年谱片段（任职、贬谪、漫游、隐居等）分段构成。提供两张图：按地理大区着色（看时空交集）与按人生类型着色（看人生轨迹），另附 50×50 同在世年数交集矩阵与历史大事年表。

## 功能特点

- 50 位诗人、324 段年谱片段，首尾相接铺满一生，无重叠无缝隙
- 双维度着色：地理大区（两京/江南/蜀中/荆湘等）与人生类型（京官/贬谪/漫游/隐居等）
- 四唐分期带 + 历史大事事件带，重大事件（武周、安史、永贞、甘露、黄巢、唐亡）画竖线
- 交集矩阵为活公式 + 蓝色色阶，改数据后整表联动
- 存疑生卒年标「约」并在名录备注异说
- 7 个工作表：读我、名录、年谱数据、甘特·地点、甘特·类型、交集、历史大事

## 技术栈

- Python + openpyxl —— 生成带样式与公式的 xlsx 工作簿
- formulas 库 —— 交付前重算校验，零公式错误
- CSV 数据源（UTF-8-SIG）—— poets / segments / events / encounters

## 使用说明

### 查看图表

用 Excel / WPS 打开 `唐朝诗人年谱甘特图.xlsx` 即可浏览。

### 重新生成

```bash
pip install openpyxl formulas
python build_xlsx.py    # 重新生成工作簿
python verify_xlsx.py   # 自验：公式重算、逐桶比对色块、图例映射、史实抽查
```

## 注意事项

- 生卒年取通行值，存疑处标「约」，学界分歧在名录备注列标注
- 着色规则：桶中点落于段内则该桶着色；短段着色于重叠最大的桶
- 修改 `data/*.csv` 后重跑两个脚本即可重新生成与复验
