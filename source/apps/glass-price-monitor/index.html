玻璃原料价格监控系统

Glass Raw Material Price Monitoring System

Next.js + React + TypeScript

项目简介

实时监控玻璃生产主要原料（纯碱、天然气、电力、锂长石、方解石等）价格变动的专业工具， 帮助玻璃制造企业及时掌握原料市场动态，优化采购决策。

核心功能

  • 多原料价格监控（纯碱、天然气、电力、锂长石、方解石等）
  • 实时数据展示，卡片式布局清晰直观
  • 行业资讯信息流，掌握市场动态
  • 本地数据存储，支持扩展至云端数据库
  • 响应式设计，支持桌面和移动设备
