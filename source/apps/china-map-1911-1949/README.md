# 山河之间 · 1911—1949 中国历史地图

## 项目介绍

1911—1949 年中国近代历史态势概览的单文件交互式网页应用。以 39 个年度画面逐年呈现民国时期的政治态势演变，配时间轴导航、自动播放与史料说明。

**注意：本图为教学示意，非精确疆界。**

## 功能特点

- 39 个年度画面（1911—1949），逐年呈现历史态势
- 自动播放（▶ 播放 / ↺ 从 1911 开始）
- 时间轴快捷跳转：1911 / 1920 / 1930 / 1937 / 1945 / 1949
- 每年「查看本年参考资料」：史料与读图说明
- 「↓ 保存本年地图 SVG」导出当年地图
- 「了解编绘方法」说明页面
- 字体子集（Noto Sans/Serif CJK）内嵌，完全离线可用

## 技术栈

- 纯 HTML / CSS / JavaScript 单文件应用，无外部依赖
- 内嵌 SVG 地图
- WOFF 字体子集内嵌

## 使用说明

### 查看网页

直接在浏览器中打开 `index.html` 文件即可查看网页效果。

- 参考资料中的外部链接需联网访问，地图本身离线可用
