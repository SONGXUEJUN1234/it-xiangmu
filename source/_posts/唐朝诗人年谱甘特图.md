## 项目简介

唐朝诗人年谱甘特图是一个用 Python 生成的 Excel 工作簿：把 50 位唐朝诗人（初唐王勃、陈子昂，盛唐李白、杜甫、王维，中唐韩愈、白居易、柳宗元，晚唐李商隐、杜牧、韦庄……）的生平装进一张甘特图。横轴 580—929 年、每 5 年一列，甘特条由年谱片段（任职、贬谪、漫游、隐居等）分段构成，纵向一眼看出诗人之间的时空交集——李杜同窗、元白并世、小李杜擦肩，都落在同一张时间轴上。

## 技术栈

- Python + openpyxl —— 生成带条件格式、活公式与冻结窗格的 xlsx 工作簿
- formulas 公式重算库 —— 交付前全表重算校验，零公式错误
- CSV 数据源（UTF-8-SIG）—— poets / segments / events / encounters 四张表，改数据重跑脚本即可再生

## 功能特点

- **50 人 × 324 段年谱**：每人片段按「主要居留地 / 主要身份」首尾相接铺满一生，无重叠无缝隙
- **双维度着色**：按地理大区（两京/江南/蜀中/荆湘/岭南……）看时空交集，按人生类型（京官/贬谪/边塞/漫游/隐居……）看人生轨迹，同一数据源两张图
- **历史大事叠加**：四唐分期带 + 18 条大事年表，武周、安史、永贞、甘露、黄巢、唐亡六大事件在甘特图上画竖线
- **交集矩阵**：50×50 同在世年数矩阵（活公式 + 蓝色色阶）+ 26 条交游事件（李杜同游梁宋、元白唱和、韩孟联句……）
- **数据严谨**：生卒年取通行值，存疑标「约」，名录备注记异说（如张若虚生年两说）；色板通过色盲安全与亮度带校验，低对比色有文字标签与图例兜底
- **7 个工作表**：读我、名录、年谱数据、甘特·地点、甘特·类型、交集、历史大事

## 本地使用

用 Excel / WPS 直接打开压缩包内的 `唐朝诗人年谱甘特图.xlsx` 即可浏览。如需修改数据重新生成：

```bash
pip install openpyxl formulas
python build_xlsx.py    # 重新生成工作簿
python verify_xlsx.py   # 自验：公式重算、逐桶比对色块、图例映射、史实抽查
```
