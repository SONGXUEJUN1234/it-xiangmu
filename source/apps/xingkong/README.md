# 星座认星镜 · 打孔图纸生成工具

眼镜式星座识别装置：硬纸板按星座亮星真实相对位置打孔，套在眼镜上，
锚点大孔对准易认亮星、歪头旋转锁定第二颗星，其余孔即指向整个星座。

## 生成图纸

    PYTHONUTF8=1 python -m pip install -r requirements.txt   # 首次
    PYTHONUTF8=1 python make_card.py 列表
    PYTHONUTF8=1 python make_card.py 猎户座 --distance 100

`--distance` 为纸板离眼距离（默认 100mm，允许 80-300）。

## 制作

1. 图纸按 **100% 实际大小**打印（关闭"适合页面"缩放），先量标尺确认为 50mm
2. 图纸贴在 300g 灰板纸/双层快递纸箱上，沿面板框裁切
3. 孔位用圆规尖/美工刀打孔：锚点 Ø5mm，其余 Ø3mm
4. 另剪两条 20×(离眼距离-15)mm 纸板作折翼，胶带粘在面板左右边（图纸有虚线标记）
5. 折翼末端用胶带固定在眼镜框，或打孔穿头带
6. 安装时印刷面（印有星名文字的面）必须朝向眼睛——装反图案会左右镜像，永远套不上星

## 使用（两星锁定法）

1. 闭一只眼，锚点大孔套住对应亮星
2. 歪头旋转，让"第二亮"孔也套住对应星 —— 图案锁定
3. 其余孔即指向星座各星（每孔旁印有星名）

## 验证

- 单测：`PYTHONUTF8=1 python -m pytest -v`
- 数字叠合（打印前做一次）：Stellarium 设本地纬度与当晚时刻，调到目标星座居中，
  与图纸孔位对比形状与手性（形状一致即对；图纸可在屏上旋转）
- 晴夜实测：先测北斗（全年可见最宽容）。锚点对准天枢，锁定后各孔错位 < 3° 算通过
  （约 6 个月轮直径）。若某孔系统性偏 >3°，先核对 star_data.py 中该星坐标

## 加新星座

在 `star_data.py` 按现有格式补一段（J2000 赤经赤纬、星等、锚点），
跑 `pytest` 确认数据不变量通过即可。
