网页内静态示意：20 位代表诗人生卒年条（按四唐分期着色）。工作簿内为 50 位诗人、逐段年谱甘特图，按地理大区与人生类型双维度着色。

工作簿结构（7 个工作表）

工作表内容
读我用法说明、两张图例、数据口径与存疑标注说明
名录50 位诗人基础表：生卒年、享年（活公式）、四唐分期、字号称谓、存疑备注
年谱数据数据源表视图：每行一段——诗人、起止年、人生类型、地理大区、事件/地点（共 324 段）
甘特·地点按地理大区（两京/江南/蜀中/荆湘……）着色的甘特图
甘特·类型按人生类型（京官/贬谪/漫游/隐居……）着色的甘特图
交集50×50 同在世年数矩阵（活公式 + 蓝色色阶）+ 26 条交游事件表
历史大事18 条大事年表；并渲染为甘特图顶部事件带与竖线（武周、安史、永贞、甘露、黄巢、唐亡）

数据与口径

  • 生卒年取通行值，存疑标「约」，名录备注记异说（如张若虚生年 647/670 两说取 670）
  • 年谱片段按「主要居留地 / 主要身份」分段，每人片段首尾相接铺满一生，无重叠无缝隙
  • 横轴每 5 年一列（580—929，共 70 桶）；重大事件在对应列画深色竖线
  • 两套 7 色板均通过色盲安全与亮度带校验；低对比色另配段级文字标签、白色隔断与图例兜底
  • 交集矩阵为活公式（COUNTIFS 思路的重算校验零公式错误），改数据后可整表联动

本地使用

直接用 Excel / WPS 打开压缩包内的 唐朝诗人年谱甘特图.xlsx 即可浏览。如需改数据重新生成：

pip install openpyxl formulas
python build_xlsx.py    # 重新生成工作簿
python verify_xlsx.py   # 自验：公式重算、逐桶比对色块、图例映射、史实抽查

数据源为 data/ 下四个 CSV（poets / segments / events / encounters，UTF-8-SIG 编码），可直接用文本编辑器或 Excel 修改。
