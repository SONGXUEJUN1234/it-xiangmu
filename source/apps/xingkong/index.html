星空·星座认星镜（下载版）

眼镜式星座识别装置：Python 命令行工具按星座亮星 J2000 真实坐标生成打孔图纸 PDF， 硬纸板打孔后套在眼镜上——锚点大孔对准易认亮星、歪头旋转锁定第二颗星，其余孔即指向整个星座。

北斗七星打孔面板示意（孔位按真实星位换算；金色描边大孔为锚点，印刷面朝眼安装）

功能特点

功能说明
真实星位打孔按 J2000 赤经赤纬计算各亮星相对位置，孔位即星位（精度 0.01–0.05 度）
两星锁定法锚点大孔（Ø5mm）套住亮星，歪头旋转让"第二亮"孔也套住对应星，图案即锁定
可调离眼距离--distance 80–300mm（默认 100mm），孔距随距离自动换算
打印校准标尺图纸含 50mm 标尺，打印后先量标尺确认为 100% 实际大小
每孔印星名孔旁印有星名，锁定后按名认星
单元测试pytest 覆盖坐标换算与星表数据不变量
星表可扩展star_data.py 按现有格式补星座即可

生成图纸

python -m pip install -r requirements.txt   # 首次
python make_card.py 列表                     # 查看支持的星座
python make_card.py 猎户座 --distance 100    # 生成图纸 PDF

Windows 下建议加 PYTHONUTF8=1 前缀运行，避免中文输出乱码。

制作与使用

  • 制作：图纸按 100% 实际大小打印 → 贴 300g 灰板纸裁切 → 锚点 Ø5mm、其余 Ø3mm 打孔 → 左右贴折翼固定在眼镜框
  • 安装：印刷面（印有星名的面）必须朝向眼睛，装反图案会左右镜像
  • 使用：闭一只眼，锚点大孔套住亮星 → 歪头旋转锁定第二颗 → 其余孔即指向星座各星
  • 验证：晴夜先测北斗（全年可见最宽容），锁定后各孔错位 < 3° 算通过
