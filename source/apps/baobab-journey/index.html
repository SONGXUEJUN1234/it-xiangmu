猴面包的树 · 作品地点地图

文字从哪里出发，地图就从哪里展开 —— 微信读书作者「猴面包的树」101 部作品、88 个已核验地点的世界地图。

在线演示由原生成环境（Manus 托管）提供，点击下方「在线演示」即可体验完整地图；本站另提供源码下载，地图地点数据托管在原环境云端，源码运行需自备数据（见下方说明）。

项目介绍

以旅行者的纸质档案册为灵感（「田野索引」设计方向），把作者在 101 部游记中写到的地点放到一张世界地图上：初始收录 136 个地点、153 条作品—地点关联，经书籍简介证据与地理编码双重核验后保留 88 个地点、99 条关联、0 条坐标错配；对阿拉斯加、北极圈等易错点做过逐点人工校验。

功能特点

能力说明
证据优先仅收录「作品简介中存在地点证据 + 具备地理编码」的地点，每条关联带证据文字与置信度（high/medium/low）
投影对齐红点叠加层与 Google Maps 嵌入底图使用同一 Web Mercator 投影、中心与缩放，修复「红点漂到海里」类错位
作品档案卡点击地点展开关联书籍封面轨道，一键跳转微信读书对应书目
近似定位标注地理编码置信不足的地点明确标注「近似定位」，不冒充精确坐标

本地运行（源码工程）

pnpm install
pnpm dev        # 开发预览（默认 3000 端口）
pnpm build      # 构建产物输出到 dist/public

提示：地点数据与三张图片素材原本经由生成环境的托管存储下发（/manus-storage/…），源码运行时需自备或替换为自己的数据文件（数据结构见 client/src/pages/Home.tsx 的 Place/Work 类型）。

数据边界

作品与封面元数据来自用户授权的微信读书接口；坐标一次性来自 OpenStreetMap Nominatim（单线程、1 请求/秒并本地缓存）；底图为 Google Maps 官方嵌入。地点收录以书籍简介证据为准，不代表作者到访的全部行程。
