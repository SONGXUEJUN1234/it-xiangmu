## 项目简介

「老字号地图」是商务部中华老字号的全国分布地图与品牌导航。已按官方名录《中华老字号企业名录_20251201》**全量收录 1450 个品牌**（覆盖 31 个省级地区），在全国示意地图上按地区与品类发现老字号，查看品牌档案，并跳转到**经过核验的网店**——其中 313 个品牌带网店入口（30 个为人工精选的详细档案）。

**注意：这是独立整理的导航原型，不是商务部或品牌官方平台，站内不发生交易。**

## 功能特点

- **全量名录**：商务部名录 2025-12 版 1450 项逐条收录，每条注明名录项次与企业名；同名多主体字号按名录分列
- **示意地图**：全国省级聚合、选省后城市级展示，重叠点按屏幕距离聚合；计划单列市条目并入所属省份
- **组合筛选**：9 大品类、省份、城市、关键词（支持特色产品如"香醋""粽子"）与「仅看可网购」
- **两级网店核验**：官方核验（品牌官网外链的店铺）与平台核验（逐店抓取天猫店铺页、标题含品牌名 + 店铺品类与认定企业一致才收录）；详情页如实标注核验方式，未核实的明示「暂未核实」
- **列表分批加载**：1450 个品牌首屏 60 张、按需「加载更多」
- **本地数据工作台**：JSON/CSV 导入导出、格式校验、纠错草稿，全部只存本地浏览器

## 技术栈

- React + Vite + TypeScript 纯静态网页，无后端、无数据库、无地图 API Key
- zod 数据校验（ID/省市/链接协议/日期/来源逐条把关），40 项自动化测试
- 底图：DataV GeoAtlas 行政区边界（开发预览用途）；中文字体 Noto CJK 子集本地打包

## 数据边界

认定依据为商务部 2025-12-01 版名录（新闻口径 1455 与名录 1450 有 5 项差异，以名录为准）；2026 年新一轮复核结果公布后名录可能变动。平台核验网店未逐一人工复核主体授权；精简条目的品类标签按企业名称初步归类，待逐条核实。医药类品牌仅作信息索引，不含诊疗建议。
